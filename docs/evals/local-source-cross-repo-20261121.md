## 判读和取舍

- **Atlas**。旧版按整段关键词做子串匹配，模型搜「搜索代码 文件读取 仓库检索」没有命中。当前版读了 loop.py 第 343–462、462–540 行和 retry.py，精简版读了 loop.py 第 360–470、470–540 行和 retry.py。两份回答都用到了真实的幂等性判断、异常白名单、剩余重试次数以及抖动退避实现。精简版还追到了架构文档、幂等键和熔断器，15 轮里用了 26 次工作区工具，当前版为 23 次。按核心结论有据计入完成，未逐句核准扩展说明。
- **Gugu-web**。旧版没有读到文件。当前版读了 Vue 入口、FastAPI 文件头、API 模块，又读了多份架构文档。精简版甚至已经读到 FastAPI 路由注册位置、Vite 配置和前端 API 服务，随后继续读 worker、runner 和子项目文档。两者均用尽 16 轮，均无最终回答。精简版的 47 次工作区操作中还有两次路径未命中。问题出在已具备解释材料后仍扩大范围。
- **表格识别**。两版都读了 main.py、README.md，识别出已提交的 main.py 只有导入语句，README 中的识别和导出是开发计划。对此题适用的结论限于测试提交，不描述用户当前未提交的本地实现。
- **pi-agent 回归**。当前版两题都交付了答案，精简版两题均触顶。当前版实现题描述了初始化和 setter 复制数组、getter 返回内部数组。架构题区分内层轮末 steering 与退出内层后的 follow-up，引用的 break L271 位于返回的 L257–272 尾段。它也说明根 README 只列出五个包。精简版架构题继续读 CLI、协议、服务端和 TUI 等材料。回归题单独统计，没有用于挑仓、改写问题或添加提示。
- **决定**。保留本轮开始时的版本，包括首轮工具搜索入口、本地发现、带行号的源码和独立尾段。放弃把现有指导整体换成短提示的候选，生产代码已恢复到本轮开始的内容。此结果只能评价整组变化，不能证明每条针对性的措辞都应保留。优先独立检验的是通用的收束行为：读到支持用户问题的代表路径后能否交付。没有再用本批仓库调新候选。
- **总体**。跨仓当前版与精简版各完成 2/3；41 → 36 轮，361,912 → 337,272 总 token，45,154 → 41,666 未命中输入，按输入加权的命中率 87.13% → 87.18%，账户余额减少 ¥0.09 → ¥0.10。旧版完成 0/3。每题每版一次，后跑版本可能复用缓存。余额差是账户级实测（分位精度），不具备请求级账单的归因精度。
