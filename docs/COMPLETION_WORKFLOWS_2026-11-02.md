# 自动化、原子能力与技能仓库完成清单

范围按本批全部采用推荐方案的授权记录于 [WORKFLOW_EVOLUTION.md](WORKFLOW_EVOLUTION.md)。实际最终提交、CI和真实模型样本结果以 #218/#219/#220/#221 的交付记录为准；此文件描述交付行为，不把模拟或未执行的验收当通过。

| 用户需求 | 实现与入口 |
| --- | --- |
| 资讯改为示例，自动化只留工作流 | 「自动化」直接打开设计页；复制“大厂开源与技术动向”草稿，官方来源核实→五条报告；按需连接发布节点。原资讯专页、旧作业创建表单移除。 |
| 伙伴新增能力、搭建工作流 | tebb或获授“自动化工作流”的伙伴可发现目录、保存参数化声明式能力、实例化并保存/读取图；实际落盘返回ID和版本。只保存草稿，不自动运行或启用发布。 |
| 画布与连线 | 全工作区设计页、专注画布与Escape返回；拖入/拖动节点、拖动或点击端口、连接表单、条件双出口、删除连接；自连/重复/环路/触发器反向连接即时拒绝，后端再校验。 |
| 飞书/视频原子化 | 字幕、飞书读取、文档、表格、群消息及资讯来源/报告为独立节点；业务适配器仍供其他模块复用。连接/机器人/视频登录移至设置，原独立视频业务页及无调用样式清理。 |
| 独立Skill仓库 | [tebb-skills](https://github.com/lkun-lea/tebb-skills)，原三份官方技能及workflow-builder；skills-source.json锁定完整提交和摘要，显式准备、固定Git对象导出、离线打包及许可溯源，不采集个人技能。 |

旧定时仍明确显示其原状态，可显式停用；不静默删除用户配置或重放旧发布。每轮执行冻结图与能力实例参数，已确认写入继续复用原回执，未知写入先核对。新图已确认发布中实际出现的资讯来源URL参与后续去重；海报及旧资讯专用分阶段发布不隐式搬入。

调试入口沿用认证automation_workflow RPC、workflow_authoring草稿工具、TaskManager与统一eval。新 `workflow_authoring` 固定验收使用真实伙伴/任务进程与认证RPC，核对能力和图产物、上游引用、布局、未触发执行和退出清理；命令见 [WORKFLOWS.md](WORKFLOWS.md)。能力及图版本回执登记为真实预算进展，同版本只计一次。能力模板不执行任意代码，不改变工具授权；需要新外部协议时仍须实现经过测试的适配器。

验证分类：自动化回归、类型检查、构建、模拟整链、真实模型、真实外部业务账户、浏览器/原生人工交互分别记录。全部初始失败保留；最终结果和未完成范围见关联issue，不把条件跳过当实机通过。v0.4.1冻结资产不变，用户其他未提交改动不纳入本批。

真实模型验收仍有缺口：[审阅收尾 #222](https://github.com/lkun-lea/tebb/issues/222)。首个样本暴露工具参数说明不足与验收取消参数错误，修正后两个干净源码样本分别使用120秒及产品默认180秒、均限制8次调用。两组都完成5项草稿工具调用并实际保存/回读1个能力和1个图，布局、引用及零执行/零发布通过；独立审阅持续生成，整体均超时。未将产物成功或口头JSON改算整体通过，凭据和进程清理已核对。两组源码为5a132f6；后续仅清理旧页面无效回调并补充本说明。
