# 确认资料、同步意图与删除围栏由同一服务管理

2026-11-03，#255 承接已确认的 #238 和账号空间 #244。云记录镜像、本机确认草稿、操作回执与离线队列放在账号内同一 SQLite 事务边界，不双写 facts.json；原本机事实仍是独立的本机来源，不因登录自动上传。统一记忆选择器直接读取该服务的有效视图，任务继续冻结现有 memory_snapshot，检查台复用真实组装与已发送记录。

本机内容版本和云版本分别管理。新修改可替代尚未发出的排队意图；已发出但结果未知的操作先按原编号核对，明确重试也保留原编号和正文。冲突不按设备时钟覆盖。删除立即停止本机使用并清除该服务保存的正文、草稿和排队正文；云端未确认时如实显示待核对，云端墓碑优先于旧队列与旧页。原 v1 对不存在身份的删除只返回 not_found，无法封住迟到的未知创建。本次尚无已部署云项目，当前单一契约改为 v2：删除不存在的记录也产生无正文永久墓碑；不提供旧协议回退。已有记录仍检查预期版本，更新过的云内容需要明确解决删除冲突。这避免为了取得创建回执而在删除后重放旧正文。

云访问通过 AccountService 的后台云客户端作用域，复用原会话刷新与未知刷新规则；同步层不读取账号注册表、不自行刷新或把令牌交给 RPC。网络只持账号操作租约，数据事务保持短暂；有界同步作业可查询、取消并随后台收尾。数据库与同步先推进，用户已确认暂未具备 SMTP；用户完成账号授权后，已创建独立组织与托管项目、部署迁移并完成真实 GoTrue/PostgREST 同步验证；邮件与实体设备/真实模型效果分别保留待验收。
