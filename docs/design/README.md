## 留存约定

- 新设计按功能目录保存：设计说明、原始图片、可编辑预览源文件、关联 issue，以及采用或替代状态。
- 原始图片与角色分层稿保留在本目录；客户端仅加载对应的优化运行资源。原稿与运行资源通过说明文件和准备脚本关联。
- `.fragment.html` 是对话预览源文件；同名 `.html` 是可独立打开的快照，保留布局与本地交互。预览不连接生产账号，不把真实用户资料、聊天、凭据或浏览器状态写入归档。
- 新实现需要更新采用状态；被替代的设计保留评审记录，但不继续进入客户端运行包。
- 本次图片通过 OpenAI 内置 imagegen 生成；界面预览由本项目编写。图片为设计素材，不包含第三方品牌角色。

独立 HTML 使用可选的在线图标/预览运行库；离线查看图片不受影响。源文件是长期维护入口，导出快照不作为另一套产品实现维护。

本次归档关联 [#273](https://github.com/lkun-lea/tebb/issues/273)。后续 UI/角色需求沿用本约定，无需再依赖聊天附件或临时目录。
