今日与个人偏好待答、进展、早晚报集中在今日。选时长、补充、展开依据、看回执和调整简报偏好都在原处完成。个人资料合入今日，开发团队移除。收到原任务回执后两端移除待答，用回执摘要承接。当天无待答时展示最近记录；完全无记录时留简短空态。
聊天与接续本地及云端共用消息版式，标识来源。展示会话缓存后后台补齐新消息。输入区选执行位置，目录会话及 Windows 原任务固定本地。手机按住说话，松手回填草稿。任务编号关联一轮请求。按账号和会话隔离，断线恢复按事件去重。不因切换执行位置重播历史或丢失上下文。
事项与日程事项展开详情并可编辑。日程从时间格创建，可拖动或直接输入时间，保存前明确飞书同步范围。脏表单提供保存、放弃和继续编辑。同步结果未知时保留记录供核对。
笔记、知识库、自动化笔记展示来源、正文和关联文件；知识库显式选择本地资料；工作流在编辑画布编排，运行结果进入执行详情。返回恢复查询与定位。替换未保存工作流前确认。删除时列出影响范围。
账号、设备与工具Android 允许记住跳过登录；登录邮箱默认 gmail.com，输入框内选域名。配对和云端操作按账号鉴权。桌面右下角打开设置，包含桌宠、模型、设备、工具、监控和评测。工具目录由用户主动拉取，展示名及用途可编辑，执行能力交给 tebb 调整。关闭设置回到原工作区。
弹窗与菜单选择器就近展开，复杂编辑在弹窗内完成。确认按钮说明动作，对破坏性操作说明对象和后果。Esc 或 Android 返回先关闭最上层，焦点回到触发处。提交中防重复；失败保留输入与重试入口。

两端共用的动效契约

普通状态反馈用 120 ms；新浮层建议入场 180 ms、退场 120 ms，缓出曲线为 cubic-bezier(.2,0,0,1)。距离使用逻辑像素或 dp。表中的数值是实现目标；产品状态在事件发生时更新，动画只负责呈现。

场景统一反馈中断、差异与降级
按下与选中按钮、时长、导航、开关在原位换色，120 ms；选中时给勾或文字，保持标签中心。桌面 hover 只改表面明度，手机触摸立即反馈。离开或禁用收回按压态。
页面与双栏同级切换仅内容淡入 120 ms；Android 跨层进入或返回用 180 ms、最多 8 dp 的定向位移。PC 分栏不联动位移。系统返回手势由 Android 驱动，取消恢复原状态。历史、键盘避让及滚动恢复直接定位。
菜单、设置与弹窗菜单以触发点为锚，弹窗淡入并上移 4；遮罩同步。抽屉从对应边进入，内容与遮罩一起退出。可从当前进度反向收起。只动顶层；错误和未保存确认留在当前层。系统文件、权限和第三方登录窗口使用平台动效。
折叠、列表与图表上下文、卡片依据就地展开或折起，180 ms。新列表项仅在可见区域淡入；图表最终值先可读。轮询、排序和回看不重播。减少动效时即时切换，并同步展开语义。
聊天流与复制新增字素 90 ms 清晰化，起点间隔 30 ms，最多 8 个活跃字素。复制成功对勾轻弹，2.5 秒后以 150 ms 淡出。重进直接显示已有文字；代码、图表直接显示。复制失败持续提示，成功反馈只随真实剪贴板回调触发。
语音与执行位置按住后以录音状态驱动按钮和波形，松手停止并保留可编辑文字。位置菜单按已选值显示勾。录音授权失败、手势取消均恢复输入态。桌面无麦克风入口时无需补一个装饰波形。
待答与回执提交后显示发送中；收到 Windows 接收回执才将卡片原位淡换成已回复摘要，180 ms。电脑离线时手机只存草稿，重连后用户确认发送。结果未知保留待核对；重复回执只更新一次。
拖动、缩放、归位拖动直接跟手。桌面归位复用弹簧 1200/80/1，无回弹。Compose 用相同质量归一后的阻尼与刚度，按可见位移曲线比对。取消回原位且不写入。分栏调整只在桌面出现；手机提供可达的编辑替代。减少动效时松手立即定位。
等待、通知、错误短操作就地更新，持续操作超过 180 ms 才显示等待反馈。一般成功提示单次淡入；错误、冲突与未知结果持续可读。后台刷新不遮挡已加载内容。操作已发出立即防重复。读屏播报关键状态一次，等待时长与动画周期分开。
桌宠与昼夜沿用米色桌宠。静息呼吸 3.6 秒一个周期，最大缩放 1.025；默认眨眼周期建议对齐到 6.3 秒。今日按昼夜使用黄光、白光。手机锚点移动以 420 ms 为上限，减少动效时直接定位。桌面拖动跟手；触碰、说话及情绪反馈回到原形。后台停止循环。
启动、思考与运行监控启动、加载、知识索引、工作流运行共用一个局部等待指示；真实进度用数值或阶段。旧启动网格、粒子、画像漂移和多重发光在新壳中收敛；清淡日不以动画填空。思考反馈保留文字和可操作的任务状态。

减少动效优先级为系统减少动态效果或应用内减少动效任一开启即生效。停用弹簧、模糊、位移和周期性装饰，直接呈现最终状态。保留任务文字、选中标记、焦点及静态进度。切换偏好当帧生效。

现有实现与待统一处

桌面已有流式字素、复制回执及拖拽归位规范。Android 桌宠当前使用 4.8 秒眨眼、420 ms 换锚点，按压有回弹；聊天等待层有 800 ms 往返倾斜。首轮 demo 需重点比对这几处，以及两端菜单和卡片退出。网络轮询、配对码有效期、简报定时属于业务时钟。

  1. 先评审首屏结构、看板原位操作、离线回复与回执后的状态，以及降低动效的体验。
  2. 确认后先做隔离 demo。Windows 和 MuMu 使用同一原任务、同样输入，分别录制普通和减少动效模式；覆盖待答、刚回复、清淡日、离线、迟到回执、失败和快速切换。
  3. 通过标准：两端状态顺序一致；手机重复点击、切后台和断线恢复后，原会话都只有一次答复；历史和缓存无闪动；键盘、返回键及读屏可独立完成。按录屏帧对照时长、落点与层级，异常需附发生的步骤。
  4. demo 验收通过再依次集成共享组件、聊天与今日、其余一级页面和设置弹窗。本页为设计评审工具，示例数据与回执均在浏览器内存中。

本轮 demo 验收（#338）：Windows Edge 与 MuMu Chrome 各自打开本页，按相同流程操作手机面板。在线、离线后确认、延迟回执和失败重试四条路径均回到单条答复，次日清淡和减少动效通过。此结果验证界面状态机；两台运行时之间的真实传输由今日任务验收单独覆盖。

手机工作区与电脑授权

今日、事项、日程、笔记、知识库和自动化共用单栏导航。手机选择已共享会话后，可以直接向电脑伙伴交待任务。电脑用户在配对设置中单独开启发起任务、维护手机日程和新增笔记三项权限。

手动编辑只开放这台手机新增的近期本机日程，改动时核对原版本。已关联事项或发布到外部的日程由电脑处理。手写笔记进入电脑的「手机笔记」，来源保留原文。手机离线时草稿留在原账号和设备下，重连后由用户提交。收到会话接收回执显示「已提交到原会话」，执行进展通过该会话查看。
