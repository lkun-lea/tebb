## 确认范围

- 画像地图按沟通方式、知识背景、长期目标、项目背景组织真实确认资料；其他资料单独保留。点击类别查看原文、来源、范围、资料更新时间及版本，不生成了解程度或性格分数。
- 三种角色共用动作与选择入口，支持待机、挥手、点头、左右指向、暂停和系统减少动态效果。使用连续关节运动，切换动作延续当前姿态；角色背后保持透明。
- 角色选择是当前账号的本机界面偏好，复用账号隔离的缓存，重开页面与客户端后保留。当前外观不进入云端语义资料协议，不作为记忆发给模型；画像资料仍复用现有同步服务。账号外观跨设备同步不在本次范围。
- 编辑、停用、删除、冲突与断连核对复用现有个人资料控制器。已保存资料与某次实际采用的记忆分别查看，不将视觉图当成真实模型调用证明。
- 默认采用漫画分身；用户可自由切换，外观不代表用户长相、能力或性格，也不替换桌宠或 AI 伙伴人设。

## 评审历史

| 预览 | 结论 |
| --- | --- |
| [画像地图 / 档案工作台](reviews/profile-map.html) | 画像地图为当前实施方向；草案内容为合成数据 |
| [圆点静态形象](reviews/bean-static.html) | 被替代：造型缺少辨识度、材质不合适 |
| [少量姿态动画](reviews/bean-frames.html) | 被替代：跳帧与衔接生硬 |
| [圆点连续动画](reviews/bean-continuous.html) | 被替代：验证连续动作方向，角色造型未采用 |

三种新角色按同一组要求生成：干净的平面漫画、暖白/炭灰/低饱和金色、完整轮廓、适合缩小显示，无黄色光晕。分层原稿每张为 4×2 格：躯干与腿、头、左上臂、左前臂与手、右上臂、右前臂与手、双眼、完整参考。原图均非动画帧表；运行时按关节连续插值。
