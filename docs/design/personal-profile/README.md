# 个人画像界面

关联 [#280](https://github.com/lkun-lea/tebb/issues/280)。2026-11-05 用户取消角色设计和动画，明确不保留本轮角色设计稿，改用最初的“我”字方案。

画像地图中心使用静态圆形“我”字标识，四周展示沟通方式、知识背景、长期目标与项目背景；其他资料有独立入口。资料原文、来源、使用范围与版本仍由已有服务提供，不根据头像生成性格分数。

最初的界面参考：[画像地图](reviews/profile-map.html)，[可编辑源](reviews/profile-map.fragment.html)。参考使用合成资料，实际功能见 [个人画像](../../PROFILE_VISUALIZATION.md)。

本轮取消的角色原画、分层稿、生成提示、人物动态概念和圆点动作稿已从当前项目目录移除；客户端相应角色资源、动作代码与准备脚本同步清理。自动化、记忆和终端等其他模块的设计资料继续按各自需求管理。
