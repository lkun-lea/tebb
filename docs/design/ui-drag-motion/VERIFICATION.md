## 浏览器观察

- 深浅主题分别实际操作看板：抓起/Escape恢复、快速二次抓取、单次方向键跨列，记录500ms的共享弹簧曲线；抬起卡片无装饰旋转，普通卡片不再裁切旧阴影。
- 侧栏按指针位移直接更新，Escape恢复原宽度和分隔条焦点；Home/End到达边界。靠近最窄边界松手后的逐帧宽度单调下降且不低于280px，引用内容保留。
- 日历从16:00–17:00拖到15:00–16:00，再通过原生边缘缩放保存新时长。聚焦时间块时Escape立即移除落点与浮层；原生缩放取消立即恢复原始高度，松手后时间不变；键盘预览取消也保留确认时间。
- 系统与手动减少动效分别实测：看板不创建归位动画，侧栏直接到终点，日历取消不创建归位动画。
- forced-colors下键盘焦点可见；600px没有文档横向溢出，两行看板区域不重叠，键盘可跨换行后的目标列，自动展示目标并保留视口内浮层。
