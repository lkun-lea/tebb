# 记忆重整首版交付清单（#217）

采用用户确认的「调用检查台」设计。最终提交、完整 CI 与最后一轮模型验收链接记录于 [#217](https://github.com/liukun158959-beep/tebb/issues/217)；正式冻结的 v0.4.1 发布包不包含本次后续源码改动。

| 项目 | 已实现行为 |
| --- | --- |
| 完整发送输入 | 从聊天输入框下方「记忆」进入；按任务标题、主/子伙伴、阶段与调用选择，展开有序消息、工具调用/结果、工具定义和原始 JSON。 |
| 重点信息 | 采用/排除卡片、四类来源导航、状态/冲突标记、原文与版本详情；来源导航展开对应完整消息。条带标为字符组成，不冒充 token。 |
| 四种作用域 | 用户全局、项目、伙伴、会话共用选择规则；普通助手、协作和后台任务均读取，已有任务冻结原版本。 |
| 来源编辑 | 原话、记录作者、来源会话/任务、版本及历史可查；编辑当前来源影响未来请求，旧调用不改写。 |
| 生命周期 | 候选确认、主题冲突与明确更正、到期、停止使用、撤销/恢复；模型写入核对本轮原话，更正和停止使用带准确 ID/版本。 |
| 下一次预览 | 复用首调用组装器，携带当前模型、目标、技能、附件和采样；不发模型、不建立生产任务。配置或材料变化后拒发并要求重新预览。 |
| 独立试验 | 只覆盖已核对记忆片段，先本地组装再明确试跑；一次模型调用、90秒、0执行工具，不自动写回；可查实际发送快照、结果、取消和原操作编号。 |
| 内容清理 | 先预览关联范围，明确勾选本机调用文件；已停用来源可连旧版本清理，逐项报告残留/部分失败，不承诺服务商及语义副本已删除。 |
| AI 调试 | 本机认证 memory_debug RPC、既有任务查询/取消与调用追踪；五项 memory_* 任务质量用例复用现有评测入口。 |
| 清理旧实现 | 删除固定伙伴偏好弹窗和无效样式，移除上次请求追加草稿的参考逻辑；复用原生 WorkspaceDialog、Atlas、既有存储与任务管理。 |

首轮真实模型使用 MiMo v2.6 Flash：5项全部通过，6次实际调用，0执行工具；输入4160、输出517 tokens，费用未知。核对的是固定合成代号的真实输出、实际输入摘要、跨作用域排除及试验不写回，不能推为普遍任务能力。补齐配置指纹后的最终候选需按同一固定任务再验收，结果见 issue；前面的成功与失败记录分别保留。

本地回归、类型检查和构建在隔离候选运行，完整结果以最终候选记录及 CI 为准。早期验收入口语法、试验预算收尾预留、评测队列选错的失败记录均保留；旧候选未完成的广回归记为取消，不计通过。当前源码不包含用户其他未提交工作。

浏览器/原生可视交互验收尚未完成：computer-use 因无法可靠识别 Windows 浏览器当前 URL 而停止，未继续界面控制。页面行为已有组件测试和接口/工作进程验证，此项不算人工验收通过。原始黑屏 #193、安装矩阵 #174 和性能 #97 继续按原 issue 跟进。

现有限制：只预测已存在会话的新消息首调用；后续路由、工具结果、未保存新会话与运行中补充不补造。语义矛盾不做自动全覆盖判断。旧记录缺少来源时明确未知，停用不等于全面遗忘。

使用方式及可复制的隔离调试命令见 [MEMORY_REDESIGN.md](MEMORY_REDESIGN.md)。源码更新后重启开发客户端，从聊天输入框下方「记忆」进入。
