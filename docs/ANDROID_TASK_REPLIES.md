# Android 在局域网回答 Windows 待答任务

## 使用

Windows 在「设置 → 账号与空间」登录并重启切换到目标账号。手机首次启动可用同一项目的已有邮箱账号登录，也可点「跳过登录」进入本地主聊。手机会记住访客选择，重启后直接进入聊天。选择云端执行或打开「我的电脑」时再登录，验证成功后继续刚才的操作。取消登录会保留草稿。进入页面后可点选发现的电脑或扫描 Windows 配对码，在 Windows「Android 手机配对」核对六位码并允许。只有经过批准的手机可以读取和回复该账号空间的待答任务。本机空间不能配对，旧版授权需要两端解除后重新申请。

部署方先将 `supabase/migrations/20261123000000_mobile_lan.sql` 应用到使用现有账号的 Supabase 项目，并配置邮箱验证码。构建 APK 时提供与桌面同项目的 `TEBB_CLOUD_URL`（HTTPS）和 `TEBB_CLOUD_PUBLISHABLE_KEY`（sb_publishable_ 公开密钥）。登录态保存在 Android 进程内，进程重启后用原账号重新登录即可恢复设备授权。

手机通过 UDP 41926 在本地网段发现电脑，Windows 使用同账号十分钟有效的凭据验证随机挑战，加密返回电脑名称、HTTPS 端口、证书指纹及一次性邀请。二维码与列表共用同一个申请入口，每次查询和回答还要验证账号签名与设备凭据。名下已有配对的电脑通过本地保存的地址重连。路由器须允许设备间广播和直连，Windows 防火墙须允许 tebb 的局域网 UDP 与入站 HTTPS。账号验证与凭据续期需要访问认证服务，任务内容仅经局域网传输。

Android 主聊天在前台每 2.5 秒读取当前账号的待答快照。单个待答问题自动引用，多个时点选。按住声波键开始中文听写，松手后可修改文字，检查「正在回复」的任务名再发送。Windows 确认接收后，气泡下方显示「Windows 已接收」。在电脑上打开原会话即可查看同一运行的后续进度和最终回答。

## 回执与恢复

任务列表来自 tebb 协作服务的 needs_input 运行，包含会话、运行、问题版本、标题及提问。Windows 使用桌面补充文字的同一状态事务，核对会话、原运行与版本后交回调度。重复提交相同版本和相同文字会复用持久回执。电脑提前处理了问题、授权失效或网络中断时，手机保留草稿。可以核对引用后重试，或手动取消引用。

电脑确认配对后，手机保存受固定证书指纹保护的局域网端点和专用凭据。邀请有时间限制，批准后的任务端点独立于邀请有效期。后端重启会尝试在原 IP 与端口恢复；如果 Wi-Fi 地址变化或证书到期，需要重新配对。解除配对会撤销授权。手机在前台恢复轮询，后台不持续请求。

## 验证

仓库根目录执行以下命令。测试使用临时数据库、Windows 本机 TLS 监听与隔离的模型响应，检查授权、问题版本、并发和重复发送、账号切换、重启恢复，并核对原运行进入 succeeded 后的产物。

```powershell
uv run --locked python -m unittest tests.test_mobile_pairing tests.test_clarification tests.test_execution_flow
cd android
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

在模拟器点选输入区的「云端」，再从「待答任务」载入调试包的「单个」快照。输入区显示「Windows · 原任务」，位置锁定，右侧保留按住说话。取消引用后恢复「云端」。Windows 接收回执可用上文的配对或隔离服务测试验证。
