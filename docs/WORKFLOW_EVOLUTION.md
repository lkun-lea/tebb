# 自动化与原子能力重整

关联 #218、#219、#220、#221。2026-11-02，按用户既有“需求全部采用推荐方案”授权冻结本批推荐答案；不重复逐项确认。

## 决策树与推荐答案

| 分支 | 已采用决定 | 验收 |
| --- | --- | --- |
| 自动化入口 | 仅展示可视化工作流；独立全工作区设计页，返回不丢草稿 | 主入口无旧资讯/旧作业表单，画布可放大、缩放、连线和删除 |
| 连接 | React Flow端口拖动/点击，加明确的连接表单 | 自连、重复、环路、指向触发器和错误条件分支即时拒绝，后端再校验 |
| 示例 | 资讯、视频学习、飞书发布作为可复制工作流，不自动启用 | 创建后可编辑、保存、逐步运行；实际能力边界在节点中展示 |
| 能力 | 内置适配器提供权限和输入/输出；新增能力是参数化声明式定义 | AI与画布使用同一目录和实例化接口，冻结实际参数，不能上传执行任意代码 |
| AI搭建 | 伙伴能发现、创建能力、保存和读取工作流草稿 | 有真实ID/版本，不用口头成功代替落盘；模型不能启用发布或定时 |
| 业务 | 飞书/视频归可选能力，连接/登录保留设置 | 既有适配器跨模块复用；不要求Agent必须拥有全部业务工具 |
| 存量 | 保留原配置、历史和未完成回执；显式导入/停用旧定时 | 不静默删除、重放或隐藏仍在运行的旧作业 |
| Skill | 独立公开tebb-skills仓库；仅迁移已跟踪官方内容 | 固定提交获取、校验、离线打包，不复制个人技能/凭据，不启动时追latest |
| 语言 | 英文仓库说明，英文默认README和中文README相互切换 | 内容能力与限制一致；暂不做产品UI多语言 |

原子能力描述的是一个适配器的可配置操作；工作流描述触发、依赖和执行；Skill描述伙伴如何完成目标。三者不互相授予权限。首版新增声明式能力不能创造尚未实现的外部协议；需要新协议时新增经过测试的产品适配器。它不等同于任意代码插件市场。

复用现有WorkflowService的图校验、版本、SQLite回执、TaskManager、预算、取消、未知写入核对、认证RPC及统一任务评测。能力定义与图定义由工作流服务拥有，业务适配器拥有外部调用；不在客户端或模型里复制调度器。已有资讯专用流水线与新示例的能力范围分别说明，不能把搜索摘要冒充已核实五条日报。

验证先使用假模型、假飞书与隔离目录，随后有界真实模型核对保存的能力/图产物；所有失败与超时保留。每项提交与实际结果记录于各自issue；未通过的实机/浏览器/外部账户验收明确保留，冻结0.4.1不变。
